# Regex Lab

A mobile-first regex tester and learning tool. Build, test, and debug regular expressions with live match highlighting, then sharpen your skills with interactive tutorials.

## Features

**Tester**
- Live regex evaluation with match highlighting as you type
- Replace mode with `$0`/`$1`-style capture group references
- Global (`/g`) flag toggle and pattern flags
- Match navigation (e.g. `1/5`) and character counts
- Auto-logged evaluation history — tap any past pattern/text pair to restore it

**Cheat Sheet**
- Searchable token reference (character classes, quantifiers, anchors, lookaheads, boundaries, etc.)
- Each token includes a plain-language description and example usage

**Tutorials — Regex Academy**
- Progressive lessons from Easy to Advanced
- Objective-based challenges with live match overlay feedback
- Progress tracking (e.g. `0/10 Solved`)

**Saved**
- Save patterns and test text to a personal library
- Reload any saved expression instantly

**Customization**
- 6 static color themes + 6 mixed accent gradients
- Toggle visibility of bottom nav tabs (Cheat Sheet, Tutorials, Saved)
- Toggle visibility of the top action bar Save button
